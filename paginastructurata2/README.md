# Descriere generala

- pagina web structurata
- meniu in partea stanga - cu submeniu pentru capitolul 2
- sectiune continut in restul paginii
- la click pe elementele de meniu se afiseaza continutul corespunzator
- pagina aferenta capitolului 2.2 - implementeaza navigare intre imagini - un fel de slideshow

- pagina cuprinde:
 - HTML - informatiile de afisat
 - CSS - modul de afisare
 - JavaScript - actiunile care se intampla la apasarea pe butoanele de meniu si in Capitolul2.2 - pe butoanele de schimbare imagini

## Descriere pagina web
- fisierul index.html: - contine tot, cu exceptia imaginilor
- directorul imagini: - contine imaginile folosite in aplicatie

Pentru simplitate am pus totul intr-un singur fisier: index.html.
- Partea CSS se gaseste in sectiunea <style> din header.
- Partea JavaScript - in sectiunea <script> din header.
  - cuprinde doua clase
    - una pentru meniu (articolele de meniu functioneaza ca niste tab-uri - doar ca sunt afisate vertical)
    - una pentru a afisa imaginile din Capitolul2.2
